Question: Evaluate every person against every job

The idea:
* Count required abilities
* Count abilities potentially impacted by impairments
* Rank jobs with fewer conflicts

SPARQL query: PREFIX hc: <http://www.stiima.cnr.it/RientraHC#>
PREFIX sk: <http://www.stiima.cnr.it/SkAb#>
PREFIX jl: <http://www.stiima.cnr.it/JobList#>

SELECT ?person ?job

(COUNT(DISTINCT ?requiredAbility)
AS ?required)

(COUNT(DISTINCT ?conflictAbility)
AS ?conflicts)

(
100.0 *
(
COUNT(DISTINCT ?requiredAbility)
-
COUNT(DISTINCT ?conflictAbility)
)
/
COUNT(DISTINCT ?requiredAbility)
AS ?compatibility
)
WHERE {

?job jl:requires ?descriptor .
?descriptor jl:concerns ?requiredAbility .
OPTIONAL {

?person hc:isInHealthCondition ?cond .
?cond hc:involvesICFCode ?icf .

?conflictAbility sk:isTranslatedWithICFCode ?icf .

FILTER(?conflictAbility = ?requiredAbility)
}
}
GROUP BY ?person ?job
ORDER BY DESC(?compatibility)
